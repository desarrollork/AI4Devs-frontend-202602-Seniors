# Revisar SPEC

## Objetivo

Detectar ambigüedades, contradicciones y huecos.

## Precondiciones

Borrador SPEC/PRD existente.

## Pasos

1. Lista contradicciones internas.  
2. Requisitos no medibles → reformular o TODO.  
3. Dependencias con otras áreas (API, datos).  
4. Actualizar documentos con hallazgos.

## Archivos afectados

`docs/PROJECT_SPEC.md`, `docs/PRODUCT_REQUIREMENTS.md`.

## Criterios de aceptación

Lista explícita de preguntas abiertas o todas resueltas.

## Checklist final

- [ ] Contradicciones numeradas  
- [ ] Aceptación comprobable  

## Errores comunes

## Cuándo detenerse
