# Implementar tarea

## Objetivo

Ejecutar **una** tarea sin desbordar alcance.

## Precondiciones

Task aprobada; archivos listados; tests acordados.

## Pasos

1. Leer SPEC/task y reglas `.cursor/rules/`.  
2. Implementar solo rutas listadas.  
3. Ejecutar tests/comandos de `TESTING_STRATEGY.md` pertinentes.  
4. No afirmar terminado sin validación (script local o CI equivalente).

## Archivos afectados

Solo los declarados en la task.

## Criterios de aceptación

CA de task cumplidos; tests pasando.

## Checklist final

- [ ] Diff acotado  
- [ ] Sin archivos extra  

## Errores comunes

«Mejoras» no solicitadas; tocar prisma sin task.

## Cuándo detenerse

Task ambigua o conflicto con SPEC — escalar.
