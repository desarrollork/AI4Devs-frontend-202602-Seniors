# Descomponer epics, historias y tareas

## Objetivo

Desglosar entrega en tareas implementables con archivos explícitos.

## Precondiciones

SPEC + arquitectura de alto nivel alineadas.

## Pasos

1. Epics por valor entregable.  
2. Historias por epic con criterios.  
3. Tasks con ID, archivos, exclusiones (plantilla `.ai/templates/task-template.md`).  
4. Registrar en `docs/TASKS.md`.

## Archivos afectados

`docs/TASKS.md`, `docs/ROADMAP.md` opcional.

## Criterios de aceptación

Cada task tiene prueba definida y alcance acotado.

## Checklist final

- [ ] Sin mezcla de features en una task  
- [ ] Tests citados  

## Errores comunes

Tasks gigantes; olvidar exclusiones.

## Cuándo detenerse

Priorización desconocida — falta PO/tutor.
