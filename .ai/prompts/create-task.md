# Objetivo

Definir una tarea implementable a partir de SPEC.

# Contexto

ID sugerido, epic, historia, criterios de aceptación.

# Archivos implicados

Lista cerrada de rutas bajo `frontend/` o `backend/`.

# Cambios requeridos

Resumen comportamental; exclusiones explícitas.

# Restricciones

Una tarea = un objetivo entregable; sin dependencias no declaradas.

# Criterios de aceptación

Comprobables en código y/o tests.

# Tests

Tipos de test esperados y comandos (`npm test`, etc.).

# Qué no debe tocar

Archivos fuera de la lista.

# Output esperado

Markdown compatible con `.ai/templates/task-template.md`.
