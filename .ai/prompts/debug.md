# Objetivo

Diagnosticar bug de forma sistemática.

# Contexto

Síntoma, pasos reproducción, entorno, últimos cambios.

# Archivos implicados

Sospechosos iniciales (opcional).

# Cambios requeridos

Hipótesis y experimento mínimo antes de fix.

# Restricciones

No parchear sin hipótesis validada o evidencia.

# Criterios de aceptación

Causa raíz o plan siguiente si falta dato.

# Tests

Test que falla o caso manual documentado.

# Qué no debe tocar

Áreas no relacionadas.

# Output esperado

Informe corto: causa, fix propuesto, riesgos.
