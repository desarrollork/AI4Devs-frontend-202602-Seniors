# Objetivo

Revisión de código según alcance y riesgo.

# Contexto

Diff o archivos clave; SPEC/tarea; resultado de tests.

# Archivos implicados

Los tocados por el cambio.

# Cambios requeridos

Lista hallazgos: bloqueante / importante / menor con acción.

# Restricciones

Sin reescritura estética masiva; sin nuevos requisitos no en SPEC.

# Criterios de aceptación

Cada bloqueante tiene camino de resolución.

# Tests

Confirmar que suite relevante fue ejecutada.

# Qué no debe tocar

Código ajeno al diff salvo dependencia directa.

# Output esperado

Informe usando `.ai/templates/code-review-template.md`.
