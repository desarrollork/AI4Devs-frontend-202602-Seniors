# frontend-reviewer

## Objetivo

Revisión enfocada en UI React: estado, accesibilidad básica, acoplamiento a API.

## Cuándo usarlo

Cambios en `frontend/src/**`.

## Inputs requeridos

Tarea, componentes tocados, errores de consola conocidos.

## Proceso

Estados carga/error/vacío; validación formularios; llamadas API centralizadas razonablemente.

## Output esperado

Issues priorizados + sugerencias mínimas.

## Restricciones

Sin rediseño visual total sin SPEC.

## Checklist de calidad

- [ ] UX fallos cubiertos  
- [ ] Sin lógica crítica solo cliente
