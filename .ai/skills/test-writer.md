# test-writer

## Objetivo

Definir y bosquejar tests alineados con la tarea y el runner existente (Jest).

## Cuándo usarlo

Junto a implementación o en workflow `06-test-task.md`.

## Inputs requeridos

Criterios de aceptación, comandos en `docs/TESTING_STRATEGY.md`.

## Proceso

Unit/integration según cambio; casos límite y regresión mencionados en SPEC.

## Output esperado

Lista de casos + archivos de test sugeridos (sin código si la política lo restringe).

## Restricciones

Respetar ausencia de E2E hasta decisión.

## Checklist de calidad

- [ ] Happy path + fallos esperados  
- [ ] Comando de verificación citado
